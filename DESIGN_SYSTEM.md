# BND Foundation Design System

## Brand Personality

BND Foundation should feel:

* Trustworthy
* Professional
* Modern
* Community-focused
* Non-profit oriented
* Accessible
* Clean and minimal

Avoid:

* Corporate enterprise appearance
* Overly colorful layouts
* Dark themes
* Excessive animations
